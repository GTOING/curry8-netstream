# 睡眠分期电刺激控制器：用户需求整理

日期：2026-09-15。依据本次主线程用户说明。本文件记录已表达需求和未定项，尚未冻结详细接口或实验参数。

## 已明确目标

1. Curry 8 负责脑电采集，周期性向本控制器发送可变长度的合法网络包；控制器按连续采样点组装不重叠的 30 秒分析窗口。
2. 控制器接收并解码数据，调用早前训练的模型，对该 30 秒脑电进行睡眠分期。
3. 模型本体与训练不在开发任务中，本次预留接口供后续接入。
4. 用户可多选 W、N1、N2、N3、REM 中一个或多个睡眠期，作为电刺激触发条件。
5. 可将用户提供的电刺激控制代码整合进项目并优化控制；实际控制经 Rally 完成，本机目前没有 Rally。
6. 时钟同步按用户原要求留待后续电刺激代码和相关说明齐备后实现。本次收到参考脚本不自动启动同步开发。
7. 使用通用 PySide6/PyQtGraph 模板作为 UI 基础。其示例项目、五图数量、模式、字段和按钮不直接成为业务需求。
8. Curry 通信以现有 `curry8-netstream/` 为基础。

## 与根规则中旧项目背景的关系

本项目当前采集来源和目标以用户最新说明为准：Curry 8、30 秒数据块、睡眠分期与电刺激。根 AGENTS.md 中 TH25A、固定五通道、250 Hz、眨眼或网页参与者等旧项目背景不据此引入本次需求。仍遵循主线程/执行线程分工、授权、证据保留与队列维护规则。

## 最新范围修正：Windows 部署与模型暂缓

用户明确本项目后续运行于 Windows。正式平台验收改为 Windows；既有 macOS 报告仅作为开发环境证据，不作为 Windows 可用性结论或交付前置条件。模型相关先不接入，继续保留 ModelAdapter/NoModel；电刺激通信整合不以模型到位为前置条件。当前成功分期到刺激决策仅经测试替身验证，未接模型时正式程序不会自动按睡眠期产生请求。

## 2026-09-16 最新范围修正：接入单通道 ONNX

用户随后明确开始模型接入，替代上节“模型暂缓”。模型支路固定把选中通道解释为 µV，做 50 Hz 工频处理和 0.3–35 Hz 带通，输出 100 Hz，不做逐样本 z-score。用户可填写一个 Curry 通道标签；当前模型为单通道。时间点数不在控制器写死为 3000 或 6000，而从 ONNX 输入读取，并要求为 3000 的正整数倍。实现与故障行为以 [ONNX 睡眠分期合同](P_MODEL_ONNX_CONTRACT.md) 为准。

此修正优先于早期 macOS 首版描述；不自动授权真实刺激或新增手动刺激功能。
