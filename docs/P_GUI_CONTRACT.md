# P-GUI 界面整理合同

日期：2026-09-16。用户最新要求：EEG 波形由 Curry 8 查看，本控制器不再显示右侧脑电图，安排一轮 GUI 修改整理与优化。

## 决定与替代范围

移除本应用实时及离线回放中的 EEG 波形展示，包括右侧绘图区域、空白画布、分隔器、绘图专用交互和降采样渲染。不是默认折叠或隐藏后继续创建绘图对象，不另加“显示脑电图”开关。此决定替代 P1 动态多通道绘图、P2 回放曲线及 P3 布局中依赖波形的要求；其余后台数据、模型、策略和记录合同继续有效。历史合同及报告保留。

## 信息结构与布局

采用紧凑控制台，充分利用窗口宽度，不将旧窄侧栏简单拉宽或留下右侧空位。保留 PySide6 桌面和中文文案，不迁移到网页、不新增图表。

- 顶部固定区域：应用标题、实时/历史/回放模式、连接状态、连接/断开操作及错误提示。错误不能随着设置区滚动而消失。
- 主体按操作顺序组织三个清晰区块：数据与分期摘要、刺激策略与本机模拟、会话记录与回放。刺激配置为主要操作区域；连接参数、会话详情和诊断作为次级可折叠内容。
- 数据摘要保留当前会话、最新有效块编号/样本范围、通道数/采样率、接收状态和分期结果。期别、无模型、处理中、失败等必须据实际结果显示；未接入时不生成期别或演示数据。
- 刺激区保留五期多选、显式策略、间隔/年龄、方案选择、模拟端状态、自动决策及近期事件；“仅模拟，真实刺激未接入”持续可见。按区块整理重复文案，不能删掉结果未知、历史/测试替身、记录失败等关键语义。
- 会话区保留记录开关/路径、回放打开/退出/逐块导航，以块元信息、已记录分期与刺激事件呈现回放，不显示 EEG 曲线。空会话和损坏块有明确状态。

默认窗口建议 1000×720，最小 800×600；以实际可用性调整默认尺寸。统一间距、字号层级、控件对齐及按钮优先级，不引入重型主题库、装饰动画或与控制无关元素。长路径/标签/错误支持换行或滚动，完整内容可读。窄窗口允许主体纵向滚动，主操作和错误区持续可访问。

## 数据与兼容性

不删除 EEG 接收/30 秒校验、模型输入、原始块记录或回放 reader，不改变数值、单位、采样/通道语义与 schema。无图不等于停止获取 EEG。保留完整原始数据供处理/保存；显示只更新摘要，无绘图数组生成、曲线构建及渲染。

可复用现有有界 latest 交接更新摘要，保持其与处理队列独立；没有必要重写后台架构或为了去图改变公共数据接口。清理“绘图计数”等失效文案，若计数仍存在，应准确称为界面摘要交接/替换，不能把显示替换说成原始 EEG 丢失。

保留断开/EOF 的历史标记、重连新会话、进入/退出回放时清理 pending，以及旧实时/异步事件不能覆盖当前回放的隔离。回放仍只读，不推理、不触发发送。默认 NoModel、记录关闭、目标期/实验参数未配置、模拟端与自动决策关闭；发送仍仅限本应用模拟端。

若项目源码不再引用 PyQtGraph，允许移除根依赖并更新 uv.lock；numpy 仍服务数据链路，不因去图删除。不得仅为消除依赖而修改 reference 或独立 Curry 仓库。

## 验证与证据

更新现有 UI 与集成测试中被本合同替代的曲线断言，改为同一会话/块/样本范围/期别/事件关联的摘要断言，不整段删除回放隔离、取消、关闭、资源释放测试。验证无波形组件构建，实时数据仍处理和保存，回放导航仍正确且不发送，配置锁定及默认状态不变。

最终执行 uv sync --locked 与 P1/P2/P3/Curry 完整回归。保留至少默认状态 1000×720 和 800×600 截图，并覆盖回放、长错误/长路径和刺激区可访问性；测试替身画面明确标注。

本轮改变原生崩溃所涉及的绘图路径，但去掉 QGraphicsView 不证明零屏幕或原生问题已解决。可做一次有变化的原生验证，GUI 不可用时保留证据，不反复重试、不默认切 offscreen 掩盖失败。离屏与原生结果分开报告。
