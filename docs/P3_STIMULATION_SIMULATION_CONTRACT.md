# P3 睡眠期决策与 Rally 模拟联调合同

日期：2026-09-16。依据：[需求](SLEEP_STIM_REQUIREMENTS.md)、[开发计划](../decision_records/plans/SLEEP_STIM_DEVELOPMENT_PLAN.md)、[资料分析](../reports/2026-09-15_reference_review.md)、[P2 验收](../reports/P2_STAGING_RECORDING_ACCEPTANCE.md)。

## 1. 范围与默认行为

交付目标睡眠期多选、可解释的决策模块、Rally 报文适配与本机模拟联调。当前真实模型、实验刺激配置和独立设备启停接口尚缺，本阶段不启用真实刺激。以下策略是供模拟验证的显式可配置工程能力，不代表已选定真实实验方案。

正式启动默认无模型、自动决策关闭、目标期空、触发规则未配置、刺激方案未配置。无隐含 Demo 数值，不安装同名 rally Python 包。正常界面可编辑目标期与策略，并查看缺失条件；任何实际 UDP 发送仅限本任务创建并持有的模拟服务。生产入口不接受用户指定 Rally 地址/8801 端口来解锁发送。

模拟服务只绑定 127.0.0.1 的系统分配空闲 UDP 端口（port=0），由应用管理生命周期，通过明确的“启动模拟端”操作或测试依赖注入创建；模拟状态始终可见。退出模拟端时结束自身线程/socket，不接触已有进程。停止模拟端不等于停止实际设备。

保持 P2 默认 NoModel。成功分期测试通过依赖注入的测试替身经 P2 处理链产生，不能在正式 UI 提供假模型或把手动输入当真实分期。

## 2. 策略配置与决策语义

配置包含目标期集合（W/N1/N2/N3/REM 任意子集）、enabled、trigger_mode、最小请求间隔秒数、最大结果年龄秒数、协议方案及配置版本。trigger_mode 必须明确选择，未选择不产生请求；间隔和年龄须显式填写有限数值，间隔 >=0，年龄 >0，无预置实验数值。

提供两种模拟策略供后续实验选择：

- each_matching_block：每个有效目标期块可成为一次候选，仍受间隔、年龄、重复及请求占用限制。
- enter_target_set：从一个有效非目标期块进入目标集合时产生候选。开启后第一个有效目标块也视为一次进入；目标集合内部 N2→N3 不算重新进入。失败/缺模型结果打断可用性，但不重置“上个有效块是否在目标集合”的记忆，不因此重复进入。新会话或显式配置变化重新开始一次策略周期。

通用约束：

1. 仅当前实时会话的 success 且 stage 合法结果参与候选；unavailable/failed/cancelled、回放、其他会话均不发送。
2. 决策必须带 session_id、block_id、配置版本、期别、模型标识、样本区间、允许/不允许以及具体原因。测试替身标记必须透传，不能隐去。
3. 按 block_id 单调接受结果；重复或倒序结果不重复发送，不改变策略前态。同一块跨配置更改也不可重新发送。配置只能影响之后新到达结果，不能主动重放旧 latest_processing。
4. 年龄以块接收边界 received_monotonic_ns 到决策时刻为准，不能用预测结束时间掩盖排队延迟；排队待发送时须再次检查。跨会话不比较单调时钟。缺接收时间的结果拒绝，不能猜测。
5. 请求间隔从实际发送请求时刻计算，使用单调时钟。被间隔/占用/年龄抑制的候选不留待后续补发；enter_target_set 的进入事件消耗后也不自动补发。
6. 改变配置须先关闭自动决策；UI 开启期间锁定配置字段。重新启用不清除本会话已处理块和上次发送时间。会话断开、进入回放或处理致命错误立即关闭自动决策并取消未发送候选。
7. 离开目标期只影响之后的请求判断，不自动发“停止刺激”或低幅值协议。UI 的“停止自动决策”只停止新请求，不宣称设备停止。

用户选择的策略和参数只是模拟配置，P4 真机前仍需冻结实际实验策略。不要扩展为通用脚本规则引擎、复杂稳定期/投票算法或置信度阈值选择。

## 3. 协议方案和适配接口

复用原资料的关键字、JSON 字段与错误码；不要运行或导入有网络副作用的原 Demo。

- 报文：UTF-8 的 `RealTimeControl` + 单个空格 + JSON。
- SD、FR、FD：秒；CHS：通道列表；N：名字；T：tD/tA；A：μA；tA 的 F：Hz、P：度、D：μA。tACS 的 A 为峰值，见资料。
- 校验非空唯一通道、已知类型、必需字段、有限数值及 JSON 可编码性；SD>0、FR/FD>=0 且 FR+FD<=SD。最多八个刺激通道，通道须属于显式给出的模拟初始协议刺激通道集合，返回通道不可修改。
- 真实总电流阈值/单通道上限与极性字段未冻结；方案必须标“模拟配置，未核实真机限制”。不凭 PPT 的 10mA/4mA 差异选一个默认值。tD 极性字段不猜测、不扩展供应商协议。实际参数合法性仍须 P4 确认。
- 方案可由用户选择一个明确的本地 JSON 文件（包含模拟初始通道和拟发送 payload），在 UI 显示摘要和结构错误；文件选取仅在自动决策关闭时。提供格式说明，测试参数留在测试 fixture，不自动加载为实验默认。
- 构造/解析是可单独测试的纯函数；网络适配器由一个后台执行者拥有，不能在 Qt 主线程阻塞 recv，也不能用每次发命令启动子进程的方式实现。

接口保留未来真实传输的替换点，当前正式程序只能使用受控模拟 endpoint，不能用“仅地址为 localhost”代替对本应用模拟服务实例的约束（本机也可能运行真实 Rally）。

## 4. UDP 结果、关联与取消

同时至多一个在途请求，不建立无界候选队列。为每个请求分配本地 request_id，记录 session/block/config 关联；不能把该 ID 擅自插入供应商 UDP 报文。

因为响应仅为错误码字符串、没有线协议请求 ID，适配器须避免迟到回复匹配到下一请求。可采用每次请求独立 socket、保留超时后的端口到模拟会话结束并忽略其后续包等简单可证实方式，或其他能明确隔离旧回复的实现；仅递增本地 ID 并复用同一 socket 不足以关联。

结果区分：未发送、等待响应、API 报告成功、API 报告拒绝、结果未知。RALLY_ERROR_SUCCESS 仅说明接口响应成功；不等于实际刺激发生或停止已确认。

- 校验响应来源是所持有模拟 endpoint；错误来源忽略且可诊断。
- 未知错误码/非法编码可报告无法解释响应，不能抛 KeyError 或冒充成功。
- 超时、发送后断开/取消而未确认、无法关联的响应记为结果未知，不自动重发。
- 结果未知或 API 拒绝后自动决策关闭，需用户检查后显式重新开启；不开启内部重试。模拟超时是通信参数，默认 1 秒可配置，仅为本机联调，不是未来真实设备 SLA。
- 用户关闭自动决策时，未发送候选取消；已发送请求保留等待/未知记录，不能改写为“未发送”。清理过程必须有界且 UI 可响应。

模拟服务默认返回成功；测试支持确定性拒绝、无响应、迟到/重复回复和错误来源。它只模拟协议应答，不模拟真实电流、设备停止确认或时钟同步。

## 5. 与 P2 的事件记录和模式隔离

所有决策应产生可解释事件，UI 可用有界近期摘要。启用 P2 记录时，decision、request_sent、request_outcome 等事件及策略配置快照由原会话单写者按序追加到 events.jsonl，不得让 UDP 线程直接打开同一文件。

这是 schema v1 的可选附加事件：不更改既有 block_saved/processing_result 字段及语义。reader 明确识别并校验附加事件的 session/block/request 关联，旧 P1/P2 会话仍可读，不能重写旧会话。原始块和处理结果先记录，相关决策/请求再记录；session_finished 必须在已发送请求已得到结果或明确未知之后。保留单写者直到本会话事件收口，不能向已关闭会话追加事件。

传输等待不可阻塞 EEG 接收、模型处理或 Qt 主线程；事件交接有界。记录启用时如事件无法接纳/落盘，关闭自动决策、停止实时接收并显示记录不完整，避免明知无法记录仍继续发送。不得把异步写入成功当作断电持久化保证。

回放只展示已经记录的决策和请求结果，不执行策略、不建立模拟/真实通信、不重发命令。进入/退出回放继续保留 P2 已修复的显示隔离，新旧会话的迟到 UDP/策略回调不能污染当前状态。

## 6. UI 与验收

增加可折叠刺激设置：五期复选框、显式策略/间隔/结果年龄输入、方案选择、模拟端状态及自动决策开关。持续显示“仅模拟，真实刺激未接入”，缺条件时说明原因；正常 NoModel 条件下可以配置，但不会请求刺激。不要提供伪“设备已停止”状态或可点击的真实急停按钮。

验收至少包括：

- 两种策略序列、目标期多选、空/未配置、缺模型、非法结果、重复/倒序、过期、间隔及忙碌抑制，依据确定性单调时钟测试而非长 sleep。
- 合成 TCP → P2 注入模型 → P3 决策 → 实际本机模拟 UDP → 界面/会话事件 → 只读回放的完整关联证据，保留替身标识。
- 成功/拒绝/未知码、无响应、迟到响应不能归入下一请求、错误来源、不自动重试。
- 关闭决策、断开/重连、回放与窗口退出时取消未发请求、记录已发请求状态并释放线程/socket/写者。
- P2 旧格式兼容、记录开关关闭时不创建会话文件、事件记录失败/积压的明确行为。
- 800×600 控件与固定错误区域可访问；最终 P1/P2/P3/Curry 相关完整回归。

原生 macOS 启动 139 作为独立已知限制保留，本任务不要求无变化重复尝试或擅自归因。若修改直接涉及启动路径，按改动验证并如实记录。任何模拟通过均不构成真机/刺激有效性证据。
