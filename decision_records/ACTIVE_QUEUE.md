## 当前执行任务：P4-B ONNX 分期—Rally API 启停联动

本任务把**实时且有效的 ONNX 睡眠分期结果**转换为对 Rally 当前已加载刺激协议的二值启停控制。目标睡眠期触发 `Start Stim`，非目标睡眠期触发 `Stop Stim`。不使用低电流、低频率或其他“静默协议”；本批不选择、切换或修改具体刺激范式，实验人员须先在 Rally 中加载并检查协议。

供执行人员使用的自包含任务快照已放入 [reference/CURRENT_TASK_QUEUE.md](../reference/CURRENT_TASK_QUEUE.md)。本文件仍是动态权威队列；`reference` 文件是本批交付副本，不应由执行人员反向改写为新的并行状态源。

### 已确认接口证据

- Rally UDP 请求端点：`127.0.0.1:8801`；UTF-8 命令为 `Start Stim` 和 `Stop Stim`。
- 启动成功回复：`启动刺激成功`；停止成功回复：`停止刺激成功`。现有兼容回复 `RALLY_ERROR_SUCCESS` 可保留，但不得把任意非空回复判为成功。
- Rally 回复可能来自 `127.0.0.1` 的动态 UDP 源端口，不要求回复源端口等于 `8801`；必须校验回复主机为本机、记录实际源端口并设置有限超时。
- 2026-09-19 的人工测试已观察到 API 启动和停止均能控制设备。本证据只证明工程命令链路，不证明刺激参数、安全性、生理输出、模型效果或正式实验有效性。
- 实现参考为 `reference/RallyStartStopTest.py`、`reference/START_STOP_TESTING.md` 及原始 `reference/RealtimeControl*.py`。参考文件中的固定实验时间线或参数不自动成为本项目合同。

### 冻结行为合同

1. **数据资格**：仅当前实时会话、当前连接、`ProcessingStatus.SUCCESS`、合法标签 `W/N1/N2/N3/REM`、新鲜且块序单调递增的 ONNX 结果可参与控制。回放、离线 NPY、历史结果、`NoModel`、失败、取消、不可用或过期结果绝不发送真实刺激命令。
2. **目标期设置**：继续使用 GUI 中显式选择的目标睡眠期；默认目标集合为空，真实 Rally 自动控制默认关闭。目标期映射、持续时间、确认 epoch 数、置信度阈值与具体刺激协议属于后续范式任务，本批不得擅自冻结。
3. **二值决策**：有效标签在目标集合内时期望状态为运行；不在目标集合内时期望状态为停止。重复的同向判定不得重复发送命令：已确认运行时重复目标期为 no-op，已确认停止时重复非目标期为 no-op。
4. **明确状态机**：至少区分 `DISARMED/UNKNOWN`、`STOPPED`、`STARTING`、`RUNNING`、`STOPPING`、`FAULT/UNKNOWN`；界面只能显示最后一次被 Rally 明确确认的状态，不得把“UDP 已发送”显示成“设备已启动/已停止”。
5. **启用基线**：用户每次显式启用真实自动控制时，先发送一次 `Stop Stim` 建立安全基线；只有收到精确停止成功回复后才进入 `STOPPED` 并允许后续分期触发启动。基线停止失败或超时则不允许自动启动。
6. **单请求与停止优先**：同一时刻只允许一个 Rally 请求在途；阶段快速变化不得形成无界命令队列。请求完成后基于最新合格结果重新计算期望状态，停止、断开和退出路径优先于启动。
7. **启动不确定处理**：`Start Stim` 拒绝、未知回复或超时时，不重试启动；立即做一次有界补偿 `Stop Stim`，关闭本次真实自动控制并将状态标为未知，直到停止得到明确确认。不得循环重试。
8. **故障停止路径**：模型失败、Curry 断流/断开、块序中断、用户关闭自动控制或应用正常退出时，若状态不是已确认停止，执行一次有界 `Stop Stim`。停止未获明确回复时显示 `FAULT/UNKNOWN`，提示操作者在 Rally/硬件侧独立停止；不得伪造“已停止”。
9. **真机与模拟隔离**：真实 Rally 控制与现有回环模拟器必须是互斥模式。真实模式仅允许固定本机端点 `127.0.0.1:8801`，首批不开放任意远程 IP；回放永远只能展示记录，不能重发控制命令。
10. **人工控制权**：真实控制每个应用会话都要显式确认并启用，界面提供醒目的模式、期望状态、最后确认状态、最近命令/回复及故障提示。软件按钮不是硬件急停；Rally/硬件独立停止方式必须保留并写入运行说明。
11. **会话记录**：通过现有 session 单写者追加控制事件，不改写原始 EEG。至少记录控制模式、事件类型、分期标签、块号、模型标识、目标集合、命令、发送/接收时间、回复原文、回复主机与动态端口、命令前后状态及结果类别。回放仅展示这些事件。
12. **本批不做**：不调用或改写 `RealtimeControlAPIDemo1...5.py` 来切换协议，不移植 `RealtimeControlManager.py` 的固定时间线，不设计 N2/N3 对应哪套范式，不执行正式受试者实验，不把工程启停成功解释为安全性或科研效果。
