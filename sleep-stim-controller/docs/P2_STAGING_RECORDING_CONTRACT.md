# P2 分期接口、会话记录与离线回放合同

日期：2026-09-15。主线程发布的 P2 控制性约定。

依据：[用户需求](SLEEP_STIM_REQUIREMENTS.md)、[开发计划](../decision_records/plans/SLEEP_STIM_DEVELOPMENT_PLAN.md)、[P1 验收](../reports/P1_DESKTOP_EEG_ACCEPTANCE.md)。

## 1. 阶段目标与产品默认

在已验收 P1 上增加分期接口、可选会话保存及只读回放。发布正式模型所需资料尚未到位，本阶段不加载用户任意模型文件、不安装模型框架、不训练、不生成生产环境模拟分期，不实现电刺激或同步。

本合同明确本阶段工程默认：保存默认关闭；用户在连接前选择保存父目录并启用保存，每次连接新建独立会话目录，禁止覆盖。回放通过选择已有会话目录打开，提供上一块、下一块和块选择，不实现实时倍速播放。配置和界面允许后续扩展，当前不增加实验参数。

P1 的“无记录/回放”阶段限制在 P2 被本合同替代；其数据校验、取消/退出、单位未确认、真机边界继续有效。P1 的最新块替换仅可用于绘图，不作为分期或记录丢弃规则。

## 2. 最小数据关联合同

每次实时连接有唯一 session_id；同一次连接内每个有效完整块有递增 block_id，保留 start_sample 与 end_sample_exclusive = start_sample + n_samples。会话重连必须新建，不跨连接拼接。

块上下文包含：会话/块标识、Curry DataBlock、完成接收后的 UTC 时间与本机 monotonic_ns。时间戳需在接收/校验交付边界采集，而非 UI 绘制时采集；不要标记为 EEG 精确采集时刻。不同进程或会话的单调时钟不可直接比较。

保留 labels、sample_rate_hz、数组 dtype/shape 和 units='unknown'，不转换、滤波、补零或更改单位。模型接口拿到数据时不可原位修改原始数组，保留 P1 校验入口，避免重建解码器。

## 3. 模型接入接口

在正式包中定义轻量 Python 类型/协议，具体命名与拆文件由执行者决定，语义如下：

- 模型描述：model_id、version、是否测试替身；模型输入约束由后续真实适配器声明。
- 生命周期：加载/准备、对一个块预测、关闭；传入可取消上下文。未来适配器负责其模型要求的预处理并声明，当前不猜测模型通道、单位和采样率。
- 预测成功输出 stage，必须精确属于 W/N1/N2/N3/REM；可选 confidence 仅在模型显式提供 0–1 有限数值时保存，含义由其描述声明；没有则为 null，不能计算伪置信度。
- 处理结果带 session_id/block_id、模型标识、status、stage、confidence、开始/结束本机时间和耗时、错误/跳过原因。status 至少区分 unavailable、success、failed、cancelled；非 success 的 stage/confidence 必须为空。
- 每个正常完成接纳的块都有一项可关联的处理终态；缺模型用 unavailable，不能用 W 或“预测成功”替代。重复/错误 stage 或非法 confidence 作为 failed。
- 默认接入 NoModel 实现，生产启动始终显示“模型未接入”。测试通过依赖注入使用固定/延迟/错误替身，不在正常 UI 或命令中提供伪真实结果开关。

P2 只证明接口和流水线可用。没有支持任意不可取消模型的承诺；接口要求预测合作式取消，未来真实模型无法满足时由后续合同明确进程隔离等方案，不在当前任务搭建通用插件平台。

## 4. 后台处理、积压与结束

- 在 P1 校验成功后、最新块显示交接之前，将完整块交给独立后台处理通路，顺序执行可选保存与模型处理。接收、模型/磁盘任务不得在 Qt 主线程执行。每个会话只有一个记录写者。
- 处理待办有界，执行者选择并记录固定容量或字节上限；满时终止本次实时接收并显式报告处理积压/记录不完整，不替换为最新块、不无限等待或静默丢弃。不允许 UI 未刷新导致记录漏块。
- 展示同时保留最新脑电块与最新处理结果各自的 block_id、样本区间及历史状态。晚到结果仍可作为该块记录，但不能冒充当前 EEG 的结果；新连接与回放不得被旧回调覆盖。P2 不赋予结果任何刺激许可。
- 主动断开/关闭先停止接收，已接纳且未处理的块保留保存机会，取消尚未完成的预测并记录 cancelled；已经完成的结果保留原终态。原始块完成落盘优先于结束会话。清理期间界面可响应、状态为停止中。
- P1 本地取消网络的 5 秒要求继续；P2 不对任意磁盘/第三方模型承诺固定退出上限，完成状态必须等待本阶段实际拥有的线程和写者退出。若异常 I/O 或适配器未按取消协议返回，显示未完成清理，不杀线程或虚报保存完成。
- 模型失败只产生该块 failed，继续处理后续块；存储失败/队列溢出终止本次采集并报告 error，保留已经成功保存的前缀。未完整接纳的块和结束原因通过计数/错误描述可见，不伪造完整数据集。

## 5. 会话格式 v1

使用 Python 标准库 JSON、NumPy .npy，不增加数据库或通用事务框架。具体字段集合可补充，但必须实现下面的恢复语义。

```text
session_<唯一标识>/
  manifest.json          schema_version=1、session_id、来源、配置快照、状态、计数
  blocks/
    <block_id>.npy       未经处理的已解码完整块，float32 [channel,sample]
  events.jsonl           单写者追加的有序记录
```

- 记录的是解码后原始数值，不是 TCP wire 抓包；不声称能重放握手原始字节。
- manifest 包含创建/结束 UTC、Curry 地址和握手元信息、模型描述、应用版本、recording_enabled、来源 live、终态原因。状态至少区分 recording、closed、failed；closed 可以带用户取消原因，不等于自然收满。未知/未获得元信息用 null。
- 每个保存块先写临时 .npy 并原子改名，再追加包含 block_id、相对路径、样本区间、时间、shape/dtype 的 block_saved 事件；随后记录该块 processing_result。数据文件不得 pickle；读写采用 allow_pickle=False。
- 每行 JSON 包含单调递增事件序号、事件类型、关联 ID 和时间。正常路径结果与数据先后明确，退出时 flush/关闭；manifest 通过短原子替换更新。不承诺未 fsync 数据在断电后一定存在。
- 用户选择记录启用后，会话创建失败不得继续以“已保存”开始接收。连接失败也保留实际创建的失败会话，禁止自动删除非空目录。
- reader 只把有效 block_saved 事件引用且存在/校验匹配的 .npy 视为可读块。manifest 未终结、缺 processing_result、缺文件或截断末行时标记不完整，允许查看完整有效前缀，不伪造结果。中间损坏须报告位置，不静默跳过；读取不修改原件或清理孤立文件。
- 相对数据路径只能指向所选会话内，拒绝越界路径和不支持 schema。该约束属于本 reader 正确性，无需开展一般安全审计。
- 记录关闭时不写 EEG、结果或会话文件；仅保留有界内存展示与错误，状态清楚标识“未保存”。原参考材料和已有历史报告不得当作运行输出目录。

## 6. 只读回放与 UI

实时会话及其清理未结束时不允许打开回放；回放模式下禁止实时连接，退出回放后再允许连接。复用现有图表和元信息展示，始终明确标记“离线回放”，不打开 Curry/Rally socket，不重新执行模型预测，只显示该块已记录结果。

增加连接前的保存开关、目录选择、实际会话路径/保存状态；增加分期区域（状态、对应块、期别、耗时/错误）；增加打开/退出回放与块导航。无功能按钮不展示为可用。

回放结果缺失时显示“未记录/处理未完成”，不能等同 unavailable 模型状态；数据坏损可见，可读前缀按第 5 节处理。块数较大时按需读取单块，不把整夜数组全部载入内存。

保留 P1 固定连接操作与错误、滚动设置、最小 800×600 和历史数据标记；新增长列表/结果不得挤掉关键控件。

## 7. 验收标准

- 默认无模型接收多个合成 30 秒块，结果均 unavailable，无伪分期，无记录开关时零会话文件。
- 测试适配器 success/failed/非法输出/cancelled 语义、数据不被原位改写、块/会话关联、延迟结果与重连隔离。
- 实际本机合成 TCP 经接收→处理→保存→reader→回放，核对数组、标签、样本范围、结果和序号；即使不消费 P1 显示缓冲，每个正常接纳块仍正确记录和处理。
- 可控慢处理触发有界队列满，验证可见错误和停止，无静默丢失；文件写失败、未完成会话、截断末行、缺结果、坏文件与不支持 schema 的行为。
- 回放不触发 socket 或模型，保存原件不变；打开/关闭/重连、处理期间取消、窗口关闭后线程/文件资源退出，P1 历史状态回归。
- 新 UI 离屏布局和 800×600 检查；原生 GUI 不可访问时如实记录。通过根级包含既有 P1/Curry 的最终相关完整回归。

只用测试临时目录和合成数据，不运行真实采集或实验。实现细节、fixture 复用和相称测试组合由执行者选择；参数/语义冲突报主线程，普通修复在原任务内完成。
